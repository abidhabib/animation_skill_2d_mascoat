# YouTube safety: how not to get flagged as "generic or repetitive" (written 2026-11-23)

Lesson from a creator friend: monetization switched off by an automated review ("generic or repetitive content"), appeal rejected with a standard reply. Their stickman + synthetic-voice channel was filed "in the same drawer" as mass-produced copy-paste channels. They then had to prove, in a video, that real work stands behind each episode (story bible, script, fact-check, ~1,500 planned shots, frame checks, a human team).

## What the policy targets (YouTube Partner Program "inauthentic content", checked 2026-11-23 via secondary sources; YouTube's own wording changed in July 2026, so re-read the official monetization page before big launches)
- Mass-produced, near-identical videos: same template, voice and visuals with only the topic swapped. Easy-to-replicate-at-scale content.
- Reused content: reading other people's articles/scripts word for word, re-uploading others' footage.
- NOT the trigger by itself: AI tools, an AI/cloned voice, animation, or a faceless channel. An original script with real analysis is fine. Disclosure of AI never limits reach or earning (YouTube help page 14328491).
- "Altered or synthetic content" label: required only for REALISTIC people/places/events. Cartoon animation is exempt; still, one honest line in the description is cheap insurance.

## Our risk profile (be honest)
Risks: one engine + one cast + one voice across videos, same "What If You..." packaging, fast bulk production, no on-camera human, generated voice/music/SFX.
Strengths: original scripts and analogies (oven shop, two-yous), numbers fact-checked with sources, a different set/props/camera in every shot, a human (the user) who approves everything.

## Rules for every video (add to the pre-publish check)
1. **Original insight in every video**: at least one idea/analogy/device that exists nowhere else (V03: the two-yous mirror, oven-shop co-signer, "the orders did"). Never paraphrase one competitor video line by line; use several sources and our own angle.
2. **Vary the format between videos**: different set pieces, props, palette, camera language, pacing, hook type and ending. Do not reuse a finished video's shot list with new nouns. Keep the kit; change the look per topic.
3. **Sources / "illustrative" labels: NOT used (user decision 2026-11-23).** No sources card on screen, no sources list required in the description, no "illustrative" tags on invented numbers in new clips. Keep the fact-check table internal (it is the evidence folder). Still avoid presenting invented numbers as official data when a real figure is easy to use.
4. **Human signals**: the user's name/face or hands somewhere (About page, a short real-voice intro or outro, community posts, replies to comments, pinned comment in the user's own words). The thumbnail is made by a human or visibly hand-art-directed.
5. **Metadata is unique per video**: own title, own description (3-5 original lines + chapters + sources), own tags. No copy-paste descriptions.
6. **Pace the uploads**: while the channel is new, do not dump many similar videos in a week. Quality over volume; alternate topics/formats.
7. **Disclosure**: leave "Altered content" OFF for pure cartoons (nothing realistic), but add to the description: "Narration uses an AI voice; research, scripts, sources and editing are by me." If anything photoreal or a real person's likeness/voice appears, turn the label ON.
8. **Never**: other creators' footage/characters/audio, a real person's face or voice, unverified financial claims, buy/sell advice.
9. **Keep an evidence folder per video** (for an appeal or human review): story/plan file, script drafts with dates, fact-check table with source links, shot list, a few contact sheets, the thumbnail files. V03 has `Plan - Nvidia Next Cisco.md` + script + specs already.
10. **If demonetized**: do not rage; file the appeal with the evidence folder, ask kindly for a human review, and publish the "how this is made" explainer (the friend's approach); keep the tone calm.

## Cheap upgrades we can build into the studio
- A recurring human element: the user's own short outro (real voice) or a photo/hand-drawn signature frame.
- Per-video look sheet: choose 1 new palette + 1 new set piece + 1 new transition style before drawing (kept in the plan file).
